# ⚡ MAX Hub

Script hub for **Murder Mystery 2** with an auto farm, a values/trade calculator and a low power mode for multi-window setups.

## Run

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/sega1games12-alt/MAX-Hub/main/hub.lua"))()
```

## Features

- **Auto Farm** for coins, with Auto End Round / Reset
- **Values & Trade** tabs: item values and a trade calculator
- **Aim tools:** Aim Lock, Auto Shoot, Silent Aim, Kill Aura
- **Visuals:** Player ESP, Role ESP, Gun Dropped ESP
- **Movement:** Fly, NoClip, Speed, Jump
- **Low Power mode** (Settings) for running several windows
- UI themes, Glass mode, FPS unlocker buttons

## Notes

- Values and Trade may be temporarily unavailable while the price server is being updated.
- The hub shows an anonymous online counter. It only sends a random session id, no username and no user id.
- Different executors support different functions, so something may not work everywhere.
